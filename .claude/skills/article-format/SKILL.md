# Правила оформлення статей

- Один заголовок «#» на початку файлу.
- Рівні підзаголовків не пропущено (# → ## → ###).
- Кожне зображення має змістовний опис у [ ].
- Файл кожного зображення є в папці images.
- Наприкінці є розділ «## Джерела».
- Кожне джерело — посилання [назва](адреса).
- Речення з «перший», «єдиний», «унікальний» звірено з джерелами.
- Текст зрозумілий людям 40+ без ІТ-освіти.
